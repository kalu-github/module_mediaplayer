# Android M3U8（HLS）多轨道播放器需求文档

## 一、项目概述

### 1.1 项目目标

实现 Android M3U8（HLS）播放器，支持直播、点播、多视频轨道、多音频轨道、多字幕轨道，以及完整的基础播放控制功能。

### 1.2 基本要求

- 支持 Android 6.0（API 23）及以上版本。
- 支持 M3U8（HLS）直播和点播。
- 支持多视频、多音频、多字幕轨道。
- 支持自动选择轨道和手动切换轨道。
- 支持自动码率、自定义固定码率及开播自动选择后固定码率。
- 支持硬件解码及设备能力检测。
- 支持播放器状态、事件和错误回调。
- 支持播放器资源管理与释放。
- 提供统一的播放器 API。

- 自动选择视频轨道。

### 4.3 视频轨道选择策略

**AUTO：自动码率模式**

- 根据网络带宽、缓冲状态及设备能力自动选择轨道。
- 播放过程中允许自动切换轨道。

**FIXED：固定码率模式**

- 根据指定轨道 ID 播放。
- 禁止因网络带宽变化自动切换视频轨道。
- 允许用户手动切换其他轨道。

**AUTO_THEN_FIXED：自动选择后固定模式**

- 播放开始时自动选择视频轨道。
- 首次实际选定视频轨道后锁定。
- 播放过程中禁止因网络波动自动切换轨道。
- 允许用户手动切换轨道。
- 播放源变化时重新执行轨道选择策略。

## 十六、功能验收标准

1. 单码率 M3U8 可以正常播放。
2. 多码率 M3U8 可以正常播放。
3. 可以获取所有已识别的视频轨道。
4. 可以获取所有已识别的音频轨道。
5. 可以获取所有已识别的字幕轨道。
6. 可以手动切换不同视频轨道。
7. 可以手动切换不同语言音轨。
8. 可以手动切换和关闭字幕。
9. AUTO 模式可以根据网络情况自动调整码率。
10. FIXED 模式不会因网络波动自动切换码率。
11. AUTO_THEN_FIXED 模式在首次实际选定轨道后保持固定。
12. 直播播放正常，Playlist 可以持续更新。
13. 点播支持暂停、恢复、Seek、进度查询。
14. 网络异常可以根据配置重试和恢复。
15. 播放器状态、轨道变化和错误事件能够正确回调。
16. Surface 销毁和重建后可以正常恢复画面。
17. 播放器释放后不存在持续占用的解码器、网络请求或工作线程。
18. Android 6.0 及以上目标设备能够按照其支持的媒体能力正常播放。

## 十七、实现边界

- 多轨道能力取决于媒体源实际提供的轨道。
- HLS 多码率 Variant 与独立视频、音频、字幕 Rendition 需要分别识别。
- 轨道 ID 应在当前媒体会话内保持稳定，不要求跨不同媒体源保持一致。
- 轨道切换允许必要的缓冲，不保证所有媒体源无缝切换。
- 固定码率模式不代表网络异常时永不卡顿。
- 硬件解码能力依赖 Android 设备及系统解码器。
- 加密流支持范围以具体加密方式和解密能力为准，AES-128 支持不等同于 DRM 支持。
- 所有不支持的能力必须能够查询或返回明确结果，避免静默失败。
